# DESIGN.md

# FilmBase Design Philosophy

FilmBase is not designed as a conventional web dashboard.

The product should feel like:

- a desktop-native media application
- a cinematic research archive
- a curated collector tool
- a tactile interaction system

Interaction feel is a core part of the product identity.

---

# Core UX Philosophy

## 1. Interaction Weight Matters

Transitions, motion, spacing, and timing are intentional.

Avoid overly fast or weightless UI behavior.

FilmBase should feel:

- cinematic
- deliberate
- tactile
- spatial
- atmospheric

---

## 2. Desktop Metaphor First

The UI is inspired by desktop operating systems and media software.

Core behaviors include:

- draggable windows
- traffic-light controls
- fullscreen transitions
- minimize behavior
- layered preview modes

Preserve desktop-like interaction consistency.

---

## 3. Poster-Centric Navigation

Posters are primary interaction objects.

Poster interactions should feel:

- collectible
- visual
- spatial
- immersive

Avoid reducing posters to generic thumbnails.

---

# Visual Principles

## Density

FilmBase uses medium-to-high information density.

Avoid excessive empty whitespace.

Layouts should feel:

- information-rich
- cinematic
- archival
- intentional

---

## Color

The visual palette prioritizes:

- dark neutral surfaces
- restrained contrast
- cinematic focus
- poster prominence

UI chrome should not overpower film artwork.

---

## Motion

Motion should communicate:

- hierarchy
- spatial continuity
- window state
- preview transitions

Avoid decorative or unnecessary animation.

---

# Window System

## Desktop Shell

The desktop shell is part of the experience.

The application should preserve:

- window framing
- rounded corners
- desktop layering
- shadow depth
- fullscreen transitions

---

## Traffic Light Controls

Traffic light interactions should behave consistently with desktop expectations.

Supported states include:

- close
- minimize
- fullscreen
- disabled
- hover
- pressed


Behavior consistency is more important than visual novelty.
Avoid overly experimental interaction patterns that conflict with established desktop expectations.

---

# Preview System

## Poster Preview

Preview mode should feel immersive and focused.

The transition into preview mode should preserve:

- spatial continuity
- motion smoothness
- visual hierarchy

Avoid abrupt scaling or disorienting transitions.

---

## Zoom Behavior

Poster zoom interactions should feel precise and cinematic.

Avoid:

- jitter
- layout jumping
- unstable scaling
- inconsistent positioning

---

# Film DNA Experience

Film DNA is not a generic graph visualization.

It should feel like:

- cinematic lineage exploration
- media archaeology
- relationship discovery

Relationship exploration should prioritize clarity and atmosphere over raw data density.

---

# Information Architecture

## Layered Exploration

FilmBase uses layered navigation:

Library
→ Preview
→ Info
→ Film DNA

Each layer should feel progressively deeper and more focused.

---

## Progressive Disclosure

Do not expose all information at once.

Users should progressively discover:

- metadata
- cast
- relationships
- lineage
- contextual information

through interaction.

---

# Typography

Typography should prioritize:

- readability
- density balance
- cinematic tone
- metadata scanning

Avoid playful or overly casual typography styles.

---

# UI Consistency Rules

Maintain consistency across:

- hover behavior
- transition timing
- spacing systems
- scrollbar styling
- panel hierarchy
- modal layering

Small inconsistencies accumulate quickly in desktop-style systems.

---

# Design Evolution Principles

Future design evolution should preserve:

- cinematic atmosphere
- desktop-inspired interaction
- poster-centric navigation
- tactile UI behavior
- layered exploration flow

Avoid drifting toward generic SaaS dashboard patterns.
